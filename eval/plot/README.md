# VADREX 8A Plotting

Python plotting is a local post-processing step. It reads CSV files generated by the TypeScript eval harness and writes PNG files.

## Setup

```powershell
cd C:\VADREX
python -m venv .\eval\plot\.venv
.\eval\plot\.venv\Scripts\python.exe -m pip install -r .\eval\plot\requirements.txt
```

## Generate Figures

Use the PowerShell wrapper from the repository root:

```powershell
.\eval\run-plots.ps1 -RunDir .\eval\out\<run-directory>
```

Or run one script directly:

```powershell
.\eval\plot\.venv\Scripts\python.exe .\eval\plot\plot_scaling.py `
  --input .\eval\out\<run-directory>\raw\scaling.csv `
  --output .\eval\out\<run-directory>\figures\scaling.png
```
